## 2. このポリシーの対象

ISEKAI link のカメラアプリ（camera-server）、デスクトップ視聴アプリ
（camera-client）、iOS 視聴アプリ、およびこれらが接続する当社の Identity API
とリレー（プロキシ）サーバを対象とします。

## 3. 取得する情報

### 3.1 アカウントに関する情報

本サービスの利用にはアカウント登録が必要です。認証は Auth0（Okta, Inc.）を
利用しており、当社は Auth0 を通じて次を取得します。

- メールアドレス
- 氏名・プロフィール画像等、Auth0 に登録されたプロフィール情報
- Auth0 が発行する利用者識別子

### 3.2 端末（Endpoint）に関する情報

端末を登録する際、次を当社の Identity API に送信します。

- 端末の公開鍵、およびそこから導出される端末識別子（Endpoint ID）
- 端末名（既定では `camera-server` / `camera-client` / `ios-camera-client`。
  利用者が変更した場合はその名称）
- 登録・トークン発行の日時

### 3.3 接続に関する情報

リレーを経由して通信する際、当社のサーバは次を取り扱います。

- **IP アドレスおよびポート番号**。本サービスは直接通信経路を確立するために、
  当社サーバが観測した利用者の公開 IP アドレスを取得し、通信相手に通知します。
  これは機能上必要な処理です。
- 接続識別子、Listener 識別子、接続の許可（グラント）、ペアリングコード
- 接続の開始・終了時刻、通信量等の稼働記録

### 3.4 映像

カメラアプリが送信する映像は、視聴アプリへ届けるために当社のリレーを経由し
ます。映像には人物、居室内、その他の状況が写り込む可能性があります。
取り扱いは第 5 節に記載します。

### 3.5 ログ

障害調査のため、上記のうち接続に関する情報を含む稼働ログを記録します。
利用者が診断用のログ出力を有効にした場合、そのログは当該端末内にのみ表示・
保持され、当社に送信されません。

### 3.6 当社が取得しない情報

本サービスは、プッシュ通知、広告配信、アクセス解析、およびクラッシュ・
エラー解析の外部サービスを利用していません。これらを目的として利用者の
情報を第三者へ送信することはありません。

## 4. 利用目的

1. 本サービスの提供（認証、端末の登録、接続の仲介、映像の中継）
2. 不正利用の防止、および安全性の確保
3. 障害の調査と品質の改善
4. 法令に基づく対応

## 5. 映像の取り扱い（重要）

**映像がリレーを経由する間、技術的には当社が映像の内容にアクセスし得る構成に
なっています。** 映像通信の TLS 証明書と対応する秘密鍵は当社のサーバが発行し、
カメラアプリへ配布しているためです。

- 当社は、本ポリシーに定める目的の範囲を超えて映像を閲覧・保存しません。
- 当社は映像を録画・蓄積しません。リレーは映像を転送するのみです。
- 通信相手（視聴を許可された利用者）以外の第三者へ映像を提供しません。
- カメラと視聴側との間で**直接通信経路が確立した後は、映像は当社のリレーを
  経由しません**。ただし経路の確立は、双方のネットワーク環境により成立しない
  場合があります。

「当社は技術的に映像を見ることができない」構成ではないため、その旨を明示して
います。

## 6. 第三者への提供・委託・外国への移転

### 6.1 委託

- **Auth0（Okta, Inc.）**: 認証基盤として利用します。第 3.1 節の情報が
  同社で取り扱われます。

上記のほか、法令に基づく場合を除き、あらかじめ利用者の同意を得ることなく
個人情報を第三者に提供しません。

### 6.2 外国にある第三者への個人データの移転

当社は、次のとおり外国にある第三者へ個人データを移転します。

| 移転先 | 所在国 | 移転する情報 | 移転の根拠 |
| --- | --- | --- | --- |
| Okta, Inc.（Auth0） | 米国 | 第 3.1 節の情報 | 個人情報保護法施行規則第 16 条の基準に適合する体制を整備している者への提供（同社との間でデータ処理補遺（DPA）を締結しています） |

Okta, Inc. は、本サービスの提供にあたり復処理者（サブプロセッサ）を利用します。
当社は、同社が復処理者に対して同等以上の義務を課していることを確認したうえで、
定期的にその実施状況を確認しています。

移転先の国における個人情報の保護に関する制度、移転先が講じている措置の概要、
および当社による確認の頻度・方法については、第 1 節の窓口へご請求いただければ
情報を提供します。

**第 3.2 節から第 3.5 節の情報（端末情報、接続情報、映像、稼働ログ）は、
外国にある第三者へ移転していません。**

## 7. 保存期間

| 情報 | 期間 |
| --- | --- |
| アカウント情報 | 退会まで |
| 端末の登録情報 | 端末の登録を削除するまで |
| 接続に関する稼働ログ | 取得から3年 |
| 映像 | 保存しません（中継のみ） |

## 8. 端末内に保存される情報

次の情報は利用者の端末内に保存され、当社に送信されません。

- 端末の秘密鍵（他者に渡してはならない長期の秘密です）
- Auth0 のアクセストークンおよびリフレッシュトークン
- 接続先などの設定

アプリからサインアウトすると、Auth0 のトークンは端末から削除されます。

## 10. 安全管理のために講じた措置

- **技術的安全管理措置**: 端末と当社サーバの間の通信は TLS により暗号化されます。
  端末の秘密鍵および認証トークンは、所有者のみが読み取れる権限で保存します。
  個人データへのアクセスは、業務上必要な担当者に限定しています。
- **組織的安全管理措置**: 個人データを取り扱う者を限定し、その取扱方法を
  定めた社内手順に従って運用しています。漏えい等の事案が発生した場合の
  報告および対応の手順を定めています。個人データの取扱状況および本節の
  措置について、定期的に点検し、必要に応じて見直します。
- **人的安全管理措置**: 個人データを取り扱う者に対し、その取扱いに関する
  留意事項を周知しています。
- **サーバの所在**: 当社の Identity API サーバは日本国内（石狩）、リレーサーバは
  日本国内（東京）に設置されたクラウド事業者の設備上で稼働しています。これらの
  事業者は当社の個人データを取り扱いません。
- **外国において個人データを取り扱う場合の当該外国の名称**:
  第 3.2 節から第 3.5 節の情報は日本国内で取り扱われます。第 3.1 節の
  アカウント情報については、認証基盤の提供事業者が日本リージョンを主たる保管
  場所としつつ、その復処理者を通じて**米国、ドイツおよびルーマニア**においても
  取り扱われる場合があります。また、コンテンツ配信網（CDN）の性質上、
  その所在国をあらかじめ特定することが困難な処理が含まれます。当社は、これらの
  外国における個人情報の保護に関する制度を把握したうえで、安全管理のために
  必要かつ適切な措置を講じています。
