## 2. このポリシーの対象

ISEKAI link のカメラアプリ（camera-server）、デスクトップ視聴アプリ
（camera-client）、iOS 視聴アプリ、およびこれらが接続する当社の Identity API
とリレー（プロキシ）サーバを対象とします。

## 3. 取得する情報

### 3.1 アカウントに関する情報

本サービスの利用にはアカウント登録が必要です。認証は Auth0（Okta, Inc.）を
利用しており、当社は Auth0 を通じて次を取得します。

- メールアドレス
- 氏名・プロフィール画像等、Auth0 に登録されたプロフィール情報
- Auth0 が発行する利用者識別子

### 3.2 端末（Endpoint）に関する情報

端末を登録する際、次を当社の Identity API に送信します。

- 端末の公開鍵、およびそこから導出される端末識別子（Endpoint ID）
- 端末名（既定では `camera-server` / `camera-client` / `ios-camera-client`。
  利用者が変更した場合はその名称）
- 登録・トークン発行の日時

### 3.3 接続に関する情報

リレーを経由して通信する際、当社のサーバは次を取り扱います。

- **IP アドレスおよびポート番号**。本サービスは直接通信経路を確立するために、
  当社サーバが観測した利用者の公開 IP アドレスを取得し、通信相手に通知します。
  これは機能上必要な処理です。
- 接続識別子、Listener 識別子、接続の許可（グラント）、ペアリングコード
- 接続の開始・終了時刻、通信量等の稼働記録

### 3.4 映像

カメラアプリが送信する映像は、視聴アプリへ届けるために当社のリレーを経由し
ます。映像には人物、居室内、その他の状況が写り込む可能性があります。
取り扱いは第 5 節に記載します。

### 3.5 ログ

障害調査のため、上記のうち接続に関する情報を含む稼働ログを記録します。
利用者が診断用のログ出力を有効にした場合、そのログは当該端末内にのみ表示・
保持され、当社に送信されません。

## 4. 利用目的

1. 本サービスの提供（認証、端末の登録、接続の仲介、映像の中継）
2. 不正利用の防止、および安全性の確保
3. 障害の調査と品質の改善
4. 法令に基づく対応

## 5. 映像の取り扱い（重要）

**映像がリレーを経由する間、技術的には当社が映像の内容にアクセスし得る構成に
なっています。** 映像通信の TLS 証明書と対応する秘密鍵は当社のサーバが発行し、
カメラアプリへ配布しているためです。

- 当社は、本ポリシーに定める目的の範囲を超えて映像を閲覧・保存しません。
- 当社は映像を録画・蓄積しません。リレーは映像を転送するのみです。
- 通信相手（視聴を許可された利用者）以外の第三者へ映像を提供しません。
- カメラと視聴側との間で**直接通信経路が確立した後は、映像は当社のリレーを
  経由しません**。ただし経路の確立は、双方のネットワーク環境により成立しない
  場合があります。

「当社は技術的に映像を見ることができない」構成ではないため、その旨を明示して
います。

## 6. 第三者への提供・委託

- **Auth0（Okta, Inc.）**: 認証基盤として利用します。第 3.1 節の情報が
  同社で取り扱われます。
- 上記のほか、法令に基づく場合を除き、あらかじめ利用者の同意を得ることなく
  個人情報を第三者に提供しません。

## 7. 保存期間

| 情報 | 期間 |
| --- | --- |
| アカウント情報 | 退会まで |
| 端末の登録情報 | 端末の登録を削除するまで |
| 接続に関する稼働ログ | 本サービスの提供に必要な期間 |
| 映像 | 保存しません（中継のみ） |

## 8. 端末内に保存される情報

次の情報は利用者の端末内に保存され、当社に送信されません。

- 端末の秘密鍵（他者に渡してはならない長期の秘密です）
- Auth0 のアクセストークンおよびリフレッシュトークン
- 接続先などの設定

アプリからサインアウトすると、Auth0 のトークンは端末から削除されます。
